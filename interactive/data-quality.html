5 · An illustrative contract

Write down what “good” means

A data contract makes expectations testable and gives failures a clear owner.

{
  "dataset": "warehouse.daily_pnl",
  "purpose": "same-day risk reporting",
  "expectations": {
    "freshness": "arrives by 09:00 UTC",
    "completeness": "trade_id is never null",
    "validity": "currency is ISO-4217",
    "uniqueness": "trade_id + as_of_date is unique"
  },
  "onFailure": "quarantine and page risk-data-oncall"
}
6 · The sequence

How quality becomes dependable

1. Name the useWhat decision or user does this data serve?
2. State expectationsDefine measurable rules with owners and thresholds.
3. Observe continuouslyRun checks where data enters and changes shape.
4. Make it safeRelease, warn, quarantine, or repair with evidence.
