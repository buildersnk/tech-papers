help_outline 01 — The Problem

Why old models struggled with language

Before Transformers, models like RNNs and LSTMs processed sentences one word at a time. This was slow, made it hard to remember words far apart, and couldn’t run on many computers at once.

psychology 5 Whys — Why RNNs weren’t enough

  1. Why? Language has long-range connections (e.g., “the cat … sat” — the subject and verb can be far apart).
  2. Why? RNNs forget information as they process word by word.
  3. Why? They can only look at one word at a time.
  4. Why? They can’t run in parallel — each word waits for the previous one.
  5. Why? Training became painfully slow and inaccurate for long sentences — until attention changed everything.
visibility 02 — Attention Is All You Need

The big idea: let every word look at every other word

Attention is a simple mechanism that lets the model weigh how important every word is to every other word — all at the same time.

Scaled Dot-Product Attention

Attention(Q, K, V) = softmax(QKᵀ / √d) V

Q = Query (what we’re looking for), K = Key (what we compare against), V = Value (the actual information).

architecture 03 — The Transformer Architecture

Stack of identical layers

The full model is just a bunch of identical layers stacked on top of each other — an encoder that reads the input and a decoder that generates the output. No recurrence, no convolution — just attention and simple feed-forward networks.

group 05 — Multi-Head Attention

Multiple “perspectives” at the same time

Instead of one attention mechanism, the model runs several in parallel (heads). Each head learns to pay attention to different kinds of relationships.

psychology 5 Whys — Why multiple heads?

  1. Why? One attention pattern isn’t enough for all relationships in language.
  2. Why? Some heads can learn syntax, others semantics, others coreference.
  3. Why? Running them in parallel is cheap on modern GPUs.
  4. Why? The model becomes much more expressive without getting bigger.
  5. Why? This is the secret sauce that made Transformers dominate AI.
place 06 — Positional Encoding

How the model knows word order

Since attention itself doesn’t care about order, we add special numbers (sinusoidal encodings) to each token so the model can tell “first”, “second”, “third”, etc.
